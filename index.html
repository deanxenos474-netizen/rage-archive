Running order

    Admin login

    For the site owner. Everyone else can browse and watch without logging in.

    Set the admin password

    This needs your GitHub token, so only you can do it. The site stores a scrambled fingerprint of the password, never the password itself.

    Connect to GitHub

    So the Publish button can update the site directly. You only do this once per browser.

    1. Open GitHub → new fine-grained token (signed in as you).
    2. Name it "rage site", set an expiry, and under Repository access choose Only select repositories → .
    3. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.
    4. Click Generate token, copy it, and paste it below.

    The token stays in this browser only. It's never added to the site's files. You can delete it on GitHub any time.
